# M2C Markdowns — Launching Soon

Coming-soon page for **M2C Markdowns**, the marketplace connecting makers directly to customers worldwide.

Built with Next.js, Tailwind CSS and Motion.

## Run locally

```bash
npm install
npm run dev        # http://localhost:3000
```

## Production

```bash
npm run build
npm start
```

## Structure

- `app/` — layout, global styles and the page
- `components/ComingSoon.tsx` — the coming-soon page
- `components/MakerToCustomer.tsx` — animated Maker → M2C → Customer flow
- `public/brand/` — logo and emblem
